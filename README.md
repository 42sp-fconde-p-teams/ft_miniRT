# Description

The main goal of this project is to implement a ray trace system using a graphic library, everything with C language. We have to deal with mathematic formulas and light behaviour acting over tridimentional solid shapes.

## Core concepts

- Primary rays - Cast from the camera position through each virtual screen pixel into the scene.
- Secondary rays - gom shadow rays (to lights), reflection rays, and refraction rays launched from hit points.
